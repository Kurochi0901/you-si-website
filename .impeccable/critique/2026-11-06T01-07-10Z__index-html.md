## Priority Issues
- [P1] 手機底部主按鈕「LINE 詢問推薦」繞過購物車（main.js:1032）。修法：有購物車時改「送出詢問單（N）」→ /order/，LINE 降為次要；抽屜加「確認前不需付款」說明。（clarify, layout）
- [P1] 本月精選 24 張全掛店長精選、隨機排序、出現過季商品；無送禮與新品入口。修法：固定 4–5 支附品鑑師一句話、移除區內徽章、加新品與送禮入口與資料標記。（distill, shape）
- [P1] 年齡驗證脫離設計系統且不符無障礙（按鈕 1.9–3.1:1、Arial、無 dialog 角色與焦點）。修法：先只改 CSS 套用焦茶／白底按鈕與雙線框；經同意再補 dialog 與品牌句。（polish, harden）
- [P2] 對比與小字：原價 #999 2.8:1、提示字 2.7:1、10px 徽章；按鈕無品名、cartFloat／menu-toggle 無名稱、數量欄無標籤、公告 aria-live 吵。（audit, typeset）
- [P2] 輪播無暫停／滑動、9px 圓點、隱藏投影片可被 Tab；手機固定列共 216px（27%）。（adapt, quieter）

## Persona Red Flags
Casey：27% 固定列、輪播不可滑、主按鈕丟購物車、提示框遮擋、怎麼買太深。
Jordan：生原酒／冷卸／火入／精米步合未解釋、圖內規格表過小、詢問單未說明付款時點。
Riley：重新整理順序變、24 個同名按鈕、cartFloat 無名稱、導覽位移、tab 無 tabpanel。
送禮者：無送禮入口、搜尋送禮／禮盒失敗、無包裝與到貨時間、B2B 區塊不對題。
